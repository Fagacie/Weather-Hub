## 📖 What is e-Tasmi?

**e-Tasmi** is a digital Qur'an recitation learning platform that connects **learners, instructors, and Qur'an learning sessions** in one structured environment.

Students can join recitation sessions, follow assigned Qur'an passages, submit their recitations, receive instructor evaluation and feedback, and continue practising.

Instructors can manage sessions, review student recitations, evaluate submissions, and provide learning feedback.

The platform is designed around a simple learning relationship:

<p align="center">

**👨‍🎓 Learner**  
↓  
**🎙️ Qur'an Recitation**  
↓  
**👨‍🏫 Instructor**  
↓  
**📖 Learning & Improvement**

</p>

The **AI Challenge** extends this existing learning experience by introducing an AI-assisted analysis and verification loop.

# 🚀 Recommended Demo Workflow

The best way to experience the challenge is to follow the complete learning loop.

| Step | 👨‍🎓 Student | 👨‍🏫 Instructor |
|---|---|---|
| **1** | 🔐 Log in as Student | 🔐 Log in as Instructor |
| **2** | 📚 Select a recitation session | 📚 Open the same session |
| **3** | 🎙️ Record / upload recitation | 👨‍🎓 Open the student's submission |
| **4** | 📤 Submit the recitation | 🎙️ Listen to the submitted audio |
| **5** | ⏳ Wait for automatic analysis | 📖 Review the trusted Qur'an reference |
| **6** | 🤖 AI analyzes the submission | 🤖 Review AI analysis and findings |
| **7** | ⏳ Wait for instructor verification | 🔎 Accept, Edit, Reject, or Add findings |
| **8** | 📊 Check the published result | 🚀 Publish the verified evaluation |
| **9** | 🎯 View verified learning focus | — |
| **10** | 🔁 Practice Again | — |

# 🏆 What We Added for the AI Challenge

The challenge work adds an **AI-assisted learning loop** to the existing e-Tasmi platform.

Instead of ending with an evaluation, the system connects:

**Recitation → AI Analysis → Instructor Verification → Learning Focus → Practice Again**

### Visual overview

![e-Tasmi AI Learning Loop](docs/images/ai-learning-loop.png)

The challenge focuses on turning AI-generated analysis into a **verified and actionable learning step**.

The core principle is:

> **AI analyzes. Instructors verify. Learners improve.**

---

# 📚 Trusted Qur'an Reference

For the challenge learning loop, the student's recitation is compared against a **trusted Qur'an reference**.

The implementation uses the **Quranpedia Hafs text** for the structured passage used in the comparison.

The process is intentionally separated:

```text
📖 Trusted Qur'an Reference
          ↓
   🔎 Passage Comparison
          ↓
   🤖 AI-assisted Analysis
          ↓
   👨‍🏫 Instructor Verification
          ↓
   🎯 Verified Learning Focus
```

The AI assists with analysis and explanation, while the **instructor remains the final authority** over what is published to the learner.
